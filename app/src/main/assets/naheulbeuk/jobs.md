# Métiers Naheulbeuk

Résumé des métiers jouables du JDR Naheulbeuk V4. Pour chaque métier, consulter la fiche officielle du pack V4 pour les compétences, restrictions et évolutions.

## Guerrier / Gladiateur
- Énergie Vitale augmentée par rapport à l'origine.
- Bonus offensif ou défensif au choix (selon fiche officielle).
- Peut porter toutes armes/armures compatibles avec l'origine.

## Assassin / Ninja
- Énergie Vitale = origine.
- PR naturelle max : 3
- Bonus offensif.
- Discrétion, embuscade, poisons.

## Voleur
- Énergie Vitale = origine.
- PR naturelle max : 3
- Crochetage, discrétion, pièges.

## Prêtre
- Énergie Vitale = origine.
- PR, nyctalopie, danger, magie selon le dieu vénéré.
- Accès aux sorts de prêtrise (magie psychique ou physique selon le dieu).

## Mage / Sorcier
- Énergie Vitale diminuée par rapport à l'origine.
- PR naturelle max : 2
- Apprécie la magie.
- Charge max : 10 kg, pas bouclier, pas armure 2 mains.
- Lance des sorts de magie psychique ou physique selon spécialisation.

## Paladin
- Énergie Vitale augmentée.
- PR, magie, charge, bouclier selon le dieu vénéré.
- Nécessite une relique.
- Combat + sorts divins limités.

## Ranger
- Énergie Vitale = origine.
- PR naturelle max : 4
- Polyvalence des scores.
- Compétences de survie, pistage, archerie.

## Ménestrel
- Énergie Vitale = origine.
- PR naturelle max : 2
- Non magicien.
- Bonus en prestation, représentation, baratin.

## Marchand / Négociant
- Énergie Vitale = origine.
- PR naturelle max : 3
- Non magicien.
- Peut porter bouclier.
- Modifications aux scores (négociation, évaluation).

## Ingénieur
- Énergie Vitale = origine.
- PR naturelle max : 3
- Non magicien.
- Peut porter bouclier.
- Modifications aux scores (artifices, mécanique).

## Pirate / Flibustier
- Énergie Vitale = origine.
- PR naturelle max : 3
- Non magicien.
- Peut porter bouclier.
- Compétences nautiques, combat en mer.

## Bourgeois / Noble
- Énergie Vitale = origine.
- PR selon origine.
- Non magicien.
- Peut porter bouclier.
- Richesse et contacts.

## Traîne-Patins
- Énergie Vitale = origine.
- Non magicien.
- Sans métier (peut choisir/débloquer un métier à partir du niveau 3).
